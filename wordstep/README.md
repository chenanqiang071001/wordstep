# 拾词 v3 · 考试优先义，先记1–2个

## 重点词义

翻卡、复习与看义拼写统一优先显示1–2个加粗释义，完整词典释义和其他义项折叠保留。首批覆盖200个重点词，共检查5,415处真题语境，其中5,248处可归义，167处因孤立选项、破损文本、专名或语境不足未归义。

按六级、英语一、英语二分别整理，在当前选中考试的已归义语境内排序；同义和合理引申义按明确语义组统计。每考种用固定散列选择至多14条出现位置，因此部分高频词采用抽样。每词展示检查/总出现次数、未归义数、各义项样本数和原文位置，不能解释为全部历年词义频率。第二义仅在至少出现2处且达到第一义样本数的15%时突出，减少边缘义项负担。

未经语境核对的词只显示明确标为“考频待核对”的精简词典义，不把词典第一义或原词总次数当成考试词义频次。看义拼写会隐藏包含答案的英文搭配，以免直接泄露拼写。

`sense-annotations.json` 保存义项和每个抽样出现位置的归义/空标记，不包含真题全文；`attach_senses.py` 验证并附加到 words.json。`dist/senses.js` 只对当前考试的有效标注计数，`tests/senses.test.mjs` 检查跨考试排序、未核对降级、次数分离及拼写提示。

跨手机、电脑的响应式背词应用，无需第三方依赖。个人网址：https://wordstep-ten-a-day.fluffystone8.chatgpt.site （使用同一 ChatGPT 账号登录）。

## 学习行为

- 首次使用先询问英语水平，可选填六级分数。例如六级 504 分采用“六级已过”的起始设置，默认过滤初中和高中基础词。
- 基础词依据 ECDICT 的 zk/gk 标签分类，有明确原形的屈折词继承原形级别。分数用于过滤预设，不宣称精确推断每词掌握程度。
- 基础词从推荐中排除，保留查询和考频，可手动“加入推荐词”；过滤不算学习成果。
- “这个词我已会”立即换词，不占每天总共 10 个新词的名额，后续不再推荐与复习。
- 每日只推荐在所选真题样本中检出的词，重合词共享进度。
- 保留翻卡、看义拼写、系统发音、收藏、搜索与间隔复习。
- 旧版记录兼容，水平、已会列表与手动加入项随 JSON 备份导入导出。

## 真题次数与范围

所有次数从固定版本的第三方真题文本逐卷重新统计，不用通用语料名次代替。

- 六级：AndrewYuZhenYu/cet6_exam_questions_txt_collection，2016–2026 年收录的 62 套卷面文本。包括英文题干、选项、写作提示和固定说明；缺少听力原文，不含答案解析。
- 英语一：pfoocc/201_204_kaoyan，2005–2023 年的 19 套完形、阅读文章及题干选项。
- 英语二：同一来源，2010–2023 年的 14 套完形、阅读文章及题干选项。

考研样本没有新题型、翻译与写作，未收录 2024–2026 年。第三方文本可能存在拼写、排版与漏录错误，并非官方完整语料，未经逐字人工校对。

统一 Unicode 兼容字形与大小写，用英文词元正则提取原拼写，内部单个连字符与撇号保留，移除 LaTeX 命令和注释。不合并复数、过去式等词形。一个词在一卷出现 3 次记为 3 次、1 套。0 次仅表示当前样本未检出，不表示历年从未考过。

按所选考试原词次数降序，同次数按英文字母排序。合并词库累加所选考试次数，因收录范围不同，不将次数解释为考试概率。单词详情提供考试次数、覆盖卷数、逐卷次数和来源链接。

dist/exam-papers.json 包含所有卷目、输入文件路径、SHA256、固定提交和范围；corpus-manifest.json 保存构建清单。应用与源码只分发聚合统计、清单和重建脚本，不分发真题全文。

字典仍保留 7,506 个去重词头。释义、音标来自 ECDICT 与 Qwerty Learner；考试标签补充了在对应真题中实际检出的词。实际推荐数随水平和所选考试变化。

## 运行和验证

运行 `node preview.mjs`，打开 http://127.0.0.1:4173 。无需 npm install。也可把 dist/ 上传至 HTTPS 静态托管。支持的浏览器可安装 PWA，成功缓存完整词库后可离线使用；发音依赖系统英语语音。

自动检查：

```sh
node --test tests/core.test.mjs tests/senses.test.mjs
python -m unittest discover -s tests -p test_corpus.py
```

重建：在源码包顶层运行 `python fetch_data.py` 和 `python fetch_exam_corpus.py`，分别下载公开字典与固定版本真题输入，再进入 wordstep 运行 `python build_data.py`。未下载原文时，Python 测试仅跳过独立原文重计数，其他测试仍可运行。

## 记录与迁移

localStorage 键保留 wordstep:v1，扩展 profile、knownWords、includeWords，旧用户升级后补设一次水平。旧学习记录保留。

没有自动云同步；不同浏览器、设备、域名与本地文件分别保存进度。清理浏览器前先导出，换设备后导入合并。合并按单词更新时间选择记录，合并收藏、已会项、手动加入项，保留较新水平设置，当天目标最多 10 词。
