# 拾词 Wordstep · 每天十词

面向考研英语一、英语二和大学英语六级的背词应用。每天学习 10 个新词，按当前收录真题中的原词出现次数安排学习顺序，并根据使用者水平过滤基础词。

电脑和手机均可通过浏览器使用；支持的浏览器可以将网站安装到桌面或主屏幕。

## 功能

- **先了解水平**：首次使用询问英语水平，可填写六级分数。例如填写 504 分，会采用“六级已过”的起始设置，默认跳过初中和高中基础词，两项过滤均可调整。
- **每天 10 个新词**：多个考试词库共享每天总共 10 个新词的目标，复习另外安排。相同单词共享学习进度。
- **已会就跳过**：点击“这个词我已会”立即补充另一个词，不占当天新词名额，后续不再推荐或复习该词。
- **真题次数排序**：展示原词出现次数、覆盖试卷数量和逐卷统计，并提供来源链接。
- **先记重点义**：学习卡、复习卡和看义拼写突出加粗的 1–2 个优先释义，完整词典释义可展开查看。
- **多种学习方式**：支持翻卡、看义拼写、系统发音、收藏和搜索。
- **间隔复习**：根据学习反馈安排后续复习，帮助巩固已学单词。
- **离线与备份**：在线版完整缓存后可离线学习；支持导出、导入 JSON 学习进度。

基础词依据 ECDICT 的初中、高中标签分类，有明确原形的屈折词继承原形级别。水平设置用于生成过滤预设，不代表对每个单词掌握程度的精确测评。被过滤的词仍可查询，也可手动“加入推荐词”。

## 快速开始

已提供生成好的网页文件，运行不需要安装 npm 依赖，也不需要重新下载真题。

安装 Node.js 后，在仓库根目录打开终端：

```sh
cd wordstep
node preview.mjs
```

浏览器访问 [本地预览](http://127.0.0.1:4173/)。保持终端运行，结束预览时按 `Ctrl+C`。

首次进入后设置英语水平和考试方向，即可开始当天计划。设置可以随时修改；当天已经完成的学习记录会保留。

普通网页版通过本地服务器或 HTTPS 网站访问。交付包中的独立文件“拾词-离线版.html”则可直接用浏览器打开，两种入口的进度需要通过导出、导入迁移。

## 部署到 GitHub Pages

本项目是静态网页应用，可部署到支持 HTTPS 的静态托管服务。以下步骤按本 README 下方的目录结构操作。

1. 将完整源码上传到 GitHub 仓库。使用 GitHub 免费方案部署 Pages 时，选择公开仓库。
2. 在仓库根目录新建 `docs` 文件夹。
3. 将 `wordstep/dist` **里面的所有文件和文件夹**复制到 `docs`，包括 `licenses`，确保存在 `docs/index.html`。
4. 提交并推送这些文件到 `main` 分支。
5. 打开仓库 **Settings → Pages**，在 **Build and deployment** 中选择：
   - Source：`Deploy from a branch`
   - Branch：`main`
   - Folder：`/docs`
6. 点击 **Save**。部署成功后，从 Pages 页面点击 **Visit site** 获取实际访问地址。

`docs` 是部署文件的副本。修改应用后，需要将更新后的 `wordstep/dist` 文件同步到 `docs`，再提交并推送；只修改源码目录不会自动更新这份副本。

部署步骤参考 [GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。GitHub 仓库页面用于查看源码，Pages 网址用于打开应用。

## 安装到电脑和手机

先在浏览器中打开已部署的网站网址。应用内也提供 **计划设置 → 安装 / 添加到主屏幕** 入口；是否能直接弹出安装窗口取决于浏览器支持情况。

### Windows 电脑

使用 Edge 打开网站，点击 **⋯ → 更多工具 → 应用 → 将此站点安装为应用**。部分版本的“应用”位于菜单第一层，也可使用地址栏中的安装图标。

安装后，在 Edge 地址栏输入 `edge://apps`，找到拾词的详细信息，可创建桌面快捷方式，或固定到任务栏和开始菜单。

### 安卓手机

使用 Chrome 打开网站，点击 **⋮ → 添加到主屏幕 → 安装**。部分版本直接显示“安装应用”。如果正在聊天软件的内置浏览器中浏览，可先选择用 Chrome 打开。

### iPhone / iPad

使用 Safari 打开网站，点击 **分享 → 添加到主屏幕**；如果出现“作为网页 App 打开”选项，将其开启后添加。

浏览器没有安装入口时，仍可直接通过网页学习。安装和缓存功能依赖浏览器支持，离线学习需先联网完成页面、词库和统计文件的缓存。发音使用设备的英语语音引擎，能否离线发音取决于系统是否安装英语语音。

## 真题次数的统计范围

当前词典包含 **7,506 个去重词头**。每日推荐仅使用在所选真题样本中出现过、且未被水平设置和已会列表过滤的词。

当前版本收录的真题样本：

- **六级**：2016–2026 年，共 62 套卷面文本，包含英文题干、选项、写作提示及固定说明；缺少听力原文，不含答案解析。
- **考研英语一**：2005–2023 年，共 19 套完形、阅读文章及题干选项。
- **考研英语二**：2010–2023 年，共 14 套完形、阅读文章及题干选项。

考研样本未包含新题型、翻译和写作，也未收录 2024–2026 年试题。输入来自第三方整理文本，可能存在拼写、排版和漏录问题，当前次数不等于官方完整历年统计。

统计按统一大小写后的原词拼写逐卷计算，不合并复数、过去式等词形。例如 `learn` 和 `learned` 分别统计。同一单词在一套试卷中出现 3 次，记为 **3 次、1 套**。显示 0 次只表示当前样本未检出。

推荐按所选考试的原词出现次数降序排列，同次数按字母排序。合并词库时累加所选考试的次数；由于各考试收录范围不同，累计次数不代表考试概率。

所有卷目、来源、固定版本及校验值见 [试卷清单](wordstep/dist/exam-papers.json) 和 [构建清单](wordstep/corpus-manifest.json)。应用与源码包不分发真题全文。

## 加粗词义的依据

当前版本已对 **200 个重点词**整理真题语境，共检查 **5,415 处**出现位置，其中 **5,248 处**可归义，另 **167 处**因语境不足、文本损坏等原因未归义。

六级、英语一、英语二分别统计词义样本；每个单词在每种考试中通过固定规则选取至多 14 处出现位置，因此部分高频词采用抽样。应用按当前所选考试的已归义样本突出 1–2 个更常见的意思，并展示核对覆盖率和原文位置。

**加粗表示已核对样本中的优先词义，不代表全部历年真题中已完整统计的最高频词义。** 尚未核对的词明确标为“考频待核对”，使用精简词典释义，不把单词总出现次数当作某个词义的次数。

义项与逐处标注保存在 [sense-annotations.json](wordstep/sense-annotations.json)。

## 学习进度与迁移

学习进度保存在当前浏览器的本地存储中，**没有自动云同步**。不同设备、浏览器、网站域名和本地离线文件各自保存进度。

迁移方法：

1. 在原设备打开 **计划设置 → 导出进度**，保存 JSON 文件。
2. 将文件传到新设备。
3. 在新设备或新网址打开 **计划设置 → 导入进度**，选择该文件，合并学习记录。

备份包含学习记录、收藏、水平设置、已会词及手动加入项。清理浏览器数据或更换访问网址前，请先导出备份。

## 项目结构

```text
.
├── README.md
├── data/                         # 公开字典输入及来源许可证
├── fetch_data.py                 # 下载字典输入
├── fetch_exam_corpus.py          # 下载固定版本真题输入
├── wordstep/
│   ├── dist/                     # 可直接部署的网页文件
│   ├── tests/                    # 学习逻辑、词义和语料统计检查
│   ├── preview.mjs               # 本地预览服务
│   ├── build_data.py             # 生成词库和统计结果
│   ├── exam_corpus.py            # 真题文本统计
│   ├── attach_senses.py          # 验证并附加词义标注
│   ├── corpus-manifest.json      # 语料版本与校验信息
│   ├── sense-annotations.json    # 词义及样本位置标注
│   └── LICENSE
└── docs/                         # 自行创建的 GitHub Pages 部署副本
```

应用使用 HTML、CSS 和原生 JavaScript，无需数据库。Node.js 用于本地预览和 JavaScript 检查，Python 用于数据重建和语料检查。

## 开发与验证

在 `wordstep` 目录运行：

```sh
node --test tests/core.test.mjs tests/senses.test.mjs
python -m unittest discover -s tests -p test_corpus.py
```

若未下载真题输入，Python 检查中的独立原文重计数会跳过，其余检查仍可运行。

需要重新生成数据时，在仓库根目录依次运行：

```sh
python fetch_data.py
python fetch_exam_corpus.py
cd wordstep
python build_data.py
```

下载步骤需要联网。仅运行现有应用不需要重建数据。增加试卷或更新义项时，应同步更新清单、统计结果和范围说明。

修改网页后，部署时同时更新 `sw.js` 中的缓存版本，便于新版本缓存替换旧版本；不要在公开仓库提交个人学习进度备份。
